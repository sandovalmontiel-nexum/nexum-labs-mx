- Preparación para analítica pública al publicar el sitio.
- Seguimiento de: visitas, apertura de EduDocIA, interés en servicios,

Antes de producción:
1. Publicar la web.
2. Configurar el proveedor de analítica.
3. Sustituir YOUR-DOMAIN en index.html por el dominio real.
4. Activar los eventos personalizados.

El contador local es solo para comprobar la instalación. Las métricas globales
se verán correctamente después de conectar la analítica al sitio publicado.
